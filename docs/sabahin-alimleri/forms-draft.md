## Form 3 (risk assessment): starter, to review with the supervisor

Rule: filled **jointly** by the student and the supervisor, before the experiment. This is a starting point, not text to copy untouched.

1. **Risks:** the experiment is entirely computer simulation. Hazards: long computer use (eyes, posture, breaks), mains electricity and chargers, data loss. No people, animals, chemicals, living material or hazardous devices are involved.
2. **Hazardous substances, activities or devices:** none.
3. **Safety measures:** breaks from the screen, a stable desk, undamaged cables and chargers, backups of results. If a real robot is added later, the plan and this form are revised first: moving legs and falls can pinch fingers, so work on a clear table, keep hands off the robot while it moves, and have a supervisor present.
4. **Waste disposal:** none, apart from old batteries if hardware is used, which go to a battery collection point.
5. **Safety sources:** `[ADD: the supervisor's school safety rules, the robot maker's safety manual if any]`.
